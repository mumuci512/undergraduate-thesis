# 文献报告内容规范

本规范适用于本项目新生成或修订的逐篇论文阅读报告；综述与跨文献报告按适用范围使用。章节名称和顺序可调整，但应清晰呈现以下内容。论文没有提供的信息标注“未报告”或“不适用”，不要凭推测补全。关键判断、数值及疑点应注明论文页码、表号、图号或章节，便于回查。

## 0. 阅读价值判断（放在报告最前面）

先读取 `00_management/PROJECT_STATE.md`，明确当前研究方向和近期需要解决的问题。然后粗读论文的摘要、引言与贡献、研究设定、方法图或核心公式、主要实验表、讨论与结论，先写本节的初步判断，再决定后续阅读深度。发表时间、期刊或会议水平、领域认可度及论文被引情况可作辅助线索；期刊影响因子属于期刊层面指标，不得仅凭其高低判断单篇论文是否值得读。未核实的发表信息或影响力信号标注“待核实”。

本节必须直接回答：“对于本项目当前研究方向和需求，这篇论文是否值得认真读？”简明填写以下内容；每项给出具体理由和可回查的论文依据，粗读尚不能判断的项目标注“待精读核实”，不得把作者自称的创新或效果直接写成已证实结论。
报告定稿时，本节开头先用一行写明“一句话结论、初评等级、最终等级、实际阅读方式”，再展开各项依据和阅读路线。

判断创新与突破程度时，要对照论文明确比较的既有工作，必要时核对相关原始文献。判断 Baseline 适配性时，核对任务、数据、监督信息、域或任务边界及评价协议；判断复现价值时，另考虑代码、数据、算力和实现细节是否可获得。判断实验可信度时，检查对照是否公平、消融和跨场景验证是否充分，以及结论是否得到相应结果支持。

| --- | --- | --- |
| 1. 与当前研究方向是否真正相关 |  |  |
| 2. 解决的核心问题 |  |  |
| 3. 真正的创新点 |  |  |
| 4. 明显突破还是增量改进 |  |  |
| 5. 方法是否值得借鉴 |  |  |

给出一个明确的最终阅读等级，并用一两句话说明最主要的依据。等级表示**本项目当前阶段的阅读优先级**，不等同于论文整体质量：

- **A级：强烈建议精读。** 与核心问题高度契合，对方法、基线或实验方案有直接且重要的参考价值。
- **B级：建议重点阅读。** 对某个关键问题有明确帮助，但存在适用边界或尚需核实的条件。
- **C级：选择性阅读。** 只有部分设定、方法或实验值得借鉴，当前不必完整精读。
- **D级：当前可以暂时跳过。** 与近期需求关联很弱，或关键设定明显不匹配；不表示论文质量差。

随后给出两份可执行的阅读路线：**只有 30 分钟**时，按优先顺序指出应看的实际章节、图、表、实验和公式；**有 2 小时**时，说明阅读顺序及每一步要验证的问题。只引用已见到的章节、图表和公式编号；若材料不全，按内容描述并标注编号待核实。最后从【文献综述 / 方法学习 / Baseline / 实验设计 / 寻找创新点 / 暂时无明显价值】中选出最适合的用途，可选多项但须区分主要用途与次要用途。

粗读后，A级精读全文及相关补充材料，B级精读与本课题相关的设定、方法和实验证据，C级、D级以泛读为主。无论等级如何，后续都须完成本规范的全部必需部分；泛读时对未深入核查之处明确标注，不得编造细节。完成报告后复核本节的判断与等级；若与初评不同，写明改变判断的证据。
报告开头保留初评等级、最终等级和实际采用的阅读方式，便于区分粗读判断与后续核查后的结论。

## 4. 疑点与可改进处

逐项写明发现的问题、对应论文依据、为何影响结论，以及可验证的改进或补充实验。区分论文明确承认的局限、报告人提出的疑问，以及已由证据支持的缺陷；证据不足时使用疑问句，不将猜测写为事实。
