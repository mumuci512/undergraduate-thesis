## 一、从哪些局限出发

以下数值来自 GSMF 原论文，不能当作用户复现结果。

1. **遗忘尚未解决。** 原文 Table IX 的 Potsdam 起点为 74.87%，GSMF 增量后为 61.91%，下降 12.96 个百分点。与 FT 比，GSMF 旧域高 7.09 点，但新域低 1.40 点；与 LwF 比，旧域低 0.62 点、新域高 2.01 点。应研究适应与保持的取舍，而非只提高一个综合数值。[R1，第5节]
2. **固定浅层冻结的收益并不一致。** 本次回查原文 Table VII，并对齐特征蒸馏层为 I=[1,2,3] 后，ISPRS 不冻结配置为旧/新 61.98/65.99，GSMF 冻结配置为 61.91/65.81。不冻结的另一行 62.01/66.00 使用 I=[0,1,2,3]，不能把它与冻结行的全部差值单独归因于冻结。LoveDA 的综合指标则偏向冻结。没有重复运行证据，不能据小差值认定取消冻结一定更好，但足以提出机制检验。[R1，第9节；本次直接复核原文 PDF p.11 Table VII、p.12 Table VIII]
3. **特征保持的具体贡献缺少受控分解。** GSR、DCAU 的主消融是单域结果；不足以证明它们各自减少 DIL 遗忘。多层特征约束与输出蒸馏的损失尺度、权重和作用区域值得拆开检验。[R1，第7、9—11节]
4. **仅有两域验证。** 多天气累积遗忘、域顺序变化、旧域重访和完整部署成本尚无对应证据。扩展实验本身是必要验证，不能直接宣称算法创新。[R1，第10节]

## 二、候选A：浅层权重与归一化统计分开控制

**优先级：优先做机制诊断与基线增强。** 保留 GSMF 主干与蒸馏框架，先定位什么在漂移，再决定更新范围。后续[先例核查](SHALLOW_WEIGHTS_BN_PRIOR_ART_2026-11-01.md)确认AdaBN、BNT、CN等已有权重/统计独立控制实验；因此，分离更新或四组合消融本身不作为新算法主张。

- 文献启发：天气遗忘分析指出浅层表征与 BN 运行统计变化是重要线索，预训练、增强与 Continual Normalization（CN）能减轻其两阶段实验中的遗忘。[R2]
- 直接诊断证据：R2 原文 Table 5 在不改变网络权重、只重新估计 BN 统计后，普通微调模型的旧域 CS mIoU 在 CS→Night 中由45.9%恢复至58.6%，在 CS→Rain 中由38.8%恢复至58.2%。该重估同时使用旧域与目标域图像，支持统计状态具有独立影响，但不能作为禁止旧图像访问时可直接获得的收益。
- 对 GSMF 的准确定位：作者公开实现采用自定义 requires_grad 冻结 stem 与 layer1；骨干 norm_eval=False，未见将教师或学生冻结浅层显式设为 eval。按通常训练行为推断，学生侧已有“浅层参数固定、BN统计继续更新”这一组合；候选A要检验该组合及其他组合的适用性，不能宣称 GSMF 完全没有区分参数与统计，也不能由静态代码直接认定这是其遗忘的原因。用户复现工程的实际运行状态仍待核查。
- 具体改造：明确区分卷积权重冻结、BN 仿射参数冻结和 BN 运行均值/方差冻结。对比原冻结策略、冻结浅层 BN 统计、浅层以较小学习率更新，以及 BN/CN 配置；不要一次同时替换所有组件。
- 预期机制：减少天气风格变化带来的旧域表征漂移，同时避免完全冻结阻碍夜间、浓雾等条件的适应。是否成立必须由道路实验判断。
- 诊断：在预定流检查点记录教师—学生特征差异、BN缓冲变化及各评价天气组mIoU，不依赖真实阶段结束。特征差异本身不是遗忘的充分证据。
- 消融与控制：教师参数及行为先固定；分别检验权重与统计。CN 或增强若改变源域训练配方，应记录各自起点，避免将更强初始化误归因于增量机制。
- 实现控制：BN.eval()既停止运行统计更新，也将训练前向的归一化参考切换到已保存统计；仅把更新系数设为零则仍可使用当前批次归一化。应明确实验比较的是哪一种 BN 行为，避免把两种实现混称为同一个“冻结统计”条件。
- 工程前置：若复现代码尚未检查，应确认教师始终处于推理行为、BN 缓冲与 Dropout 不随学生训练改变。报告中的代码问题是静态疑点，不代表用户当前工程仍有同样问题；修复工程行为也不应包装为算法创新。

## 三、候选B：按像素可靠性与类别覆盖调整蒸馏

**优先级：优先。** 在 GSMF 现有输出/特征蒸馏上改动损失，先保持结构与缓存条件不变。

- 文献启发：UCB 用像素不确定性和类别频率联合重加权，提示“可靠性筛选”与“类别覆盖”需要一起考虑。原研究为类增量分割、部分旧类标签缺失；不能直接移植旧/新类比例公式，也不能把其伪标签问题当成本课题完全监督数据的问题。[R3]
- 具体改造：保留新域真值分割损失；将蒸馏从统一权重改为逐像素权重。利用旧教师对新域像素的置信度，以及预测与当前真值是否一致，降低明显错误区域的约束；同时对类别权重限幅并归一化，避免道路、天空等大类支配约束。输出蒸馏与多层特征蒸馏分别消融，再考虑层级权重。
- 研究假设：过强、无差别的旧模型约束可能妨碍新条件学习；可靠性与类别均衡结合可能改善适应—保持折中。这是由文献提出的新假设，UCB 原文并未验证该方案。
- 最小消融：原双蒸馏、仅可靠性加权、仅类别均衡、二者结合。尽量匹配整体损失尺度，防止“有效蒸馏系数变小”解释全部收益。
- 关键风险：教师低熵也可能预测错误；只按置信度筛选不够。只降低蒸馏还可能增加旧域遗忘，必须同时看新旧域；当前新域完全缺失的历史类别也无法仅靠这些权重获得旧域训练信号。
- 实施时先使用固定规则和少量验证集超参数，不用旧域测试集在线调权，也不必立即增加一个复杂的权重预测网络。

## 四、候选C：固定预算的稀疏历史特征回放

**优先级：条件性备选。** 仅在允许保留历史特征和相应训练目标时开展，明确改变 GSMF 原有的历史信息访问条件。

- 文献启发：FOCUS 保存浅层特征，并从缓存插入点继续前向，以恢复后续多尺度信息；用稀疏化和域均衡采样控制回放。其证据来自医学 U-Net，完整方案冻结编码器，代码默认回放缓存预测目标，不应假定是原始 GT。[R4]
- 具体改造：在 GSMF/FPN 之前选择一个浅层缓存位置，保留少量特征及协议允许的标签或教师输出；从该位置重算后续各尺度。加入空间稀疏化，设置全程固定的总字节上限，历史域均衡取样；类别覆盖和代表性选样可借鉴智能数据选择，但其道路 DIL 实验不支持所有选样策略均显著优于随机。[R5]
- 预期机制：后续阶段不只依赖当前天气图像上的教师响应，也能直接获得历史条件约束。
- 最小消融：无回放、等预算稠密特征回放、稀疏回放、稀疏回放加均衡采样。若允许旧原图，应增加等字节 ER，并匹配总更新步数和回放比例。
- 关键风险：缓存位置之前的映射若继续变化，历史特征会失配；须冻结该部分或单独设计特征校准，不能与任意浅层解冻直接叠加。稀疏浅层特征仍可能比压缩原图占空间；按实际特征、索引、标签/输出和残留文件的总字节计费。检查行人、杆状物等小目标是否被稀疏化伤害。

## 五、候选D：用轻量适配器分担天气变化，并限制专家容量

**优先级：较大改造的备选。** 适合确实需要更小更新范围或更强隔离时选择，不宜和所有候选同时启动。

- 文献启发：MILE 的逐域 LoRA 专家与原型路由可以隔离更新，但专家数仍随域数增长；BECoTTA 提供预设容量的低秩适配器池及输入驱动路由思路。[R6、R7]
- 具体改造：先冻结 GSMF 大部分骨干，在选定卷积块或解码器加入单个小型残差适配器/低秩更新层，与全量更新比较；只有单适配器出现明显域冲突时，再验证固定数量的适配器与输入路由。GSMF 是卷积架构，不能假定可以直接照搬 MILE 的 Transformer LoRA 接入位置。
- 预期机制：限制共享参数漂移，减少更新成本；不同风格可复用不同适配器。保留有标注 DIL 损失，不能把 BECoTTA 无标签 CTTA 的原始实验成绩作为改造后的保持证据。
- 最小消融：全量更新、单适配器、同总参数预算的固定专家池；若加逐域增长专家，另报完整参数/存储增长。推理不直接提供真实天气 ID。
- 关键风险：旧专家冻结不等于整个系统不遗忘，路由变化仍会降低旧域分割。分别测真实自动路由和仅作诊断的 oracle 路由，记录路由混淆、实际激活专家数与推理时间；oracle 不作为主结果。

## 六、建议的推进顺序与评价

**D-009适用说明：本节下列“无边界数据流”建议均为特定协议下的候选，尚未采纳；训练时间组织待导师讨论，不能据此排除阶段式训练或要求实施周期教师等改造。当前明确的是对典型及模糊过渡条件进行评价。**

1. **先落实无边界数据流与算法规则。** 数据需有时间／天气强度或明确合成过渡依据，不能只拼接ACDC硬切子集。监督路线下先统一骨干、初始化、预算及选模，验证冻结／DG、连续FT和GSMF适配；有边界两阶段实验可作排错诊断。LwF教师、EWC重要性和GSMF旧模型的更新时机另定，不使用真实天气结束通知。
2. **检验A和B，保留可解释消融。** 确定基础适配和一个A、B配置后比较GSMF适配、+A、+B、+A+B；先检验收益再扩大流规模，对关键结论做多种子验证。上述适配及新增配置尚未运行，不能称严格复现原算法或已验证创新。
3. **无边界稳健性与资源验证。** 改变天气过渡顺序／速度并检查旧条件重现，记录检查点×评价天气组矩阵R[τ,d]。遗忘按首次曝光或预定参考检查点定义，不假设每域存在学完时刻；报告当前条件、最终各组、最差组、各类IoU及实际缓存、参数、推理／更新耗时与显存。
4. **根据证据选择C或D。** 历史锚定不足且允许缓存时考虑C；共享更新冲突明显、更新预算有限时考虑D。各方案是否成为最终路线由用户与导师决定，当前不登记为已采纳。

无边界适配还须检查：C的缓存更新与“域均衡”是否依赖真实域编号，D的专家建立／路由是否依赖真实阶段；自行检测或周期规则必须声明，不能把真实切换点藏在数据加载器或优化器重置中。具体域标签权限仍待确定；原版有边界或oracle结果单列参考。

## 七、第二页“怎么做”的建议文案

页面按用户要求简述全部四项，前两项标为优先、后两项标为备选，并保留统一验证安排。下列主线与详细步骤作为口头讲解参考，四套方法均未被登记为必须完成的最终路线。

本节保留2026-11-01已制作汇报的历史文案；后续汇报应按D-009说明典型及过渡条件覆盖目标，以及训练数据时间组织待导师讨论的状态；不从“逐阶段”或“无明显边界”预先推定训练协议。

**主线：基于 GSMF 的浅层稳定性与自适应蒸馏优化（拟研究）**

1. **道路迁移与问题定位**：在 Cityscapes、ACDC 建立多天气域增量基线，逐阶段记录新域性能与旧域遗忘。
2. **优化浅层更新**：分离卷积权重冻结与 BN 统计更新，对比归一化配置，分析天气变化下的表征漂移。
3. **优化蒸馏约束**：结合教师可靠性与类别分布调整像素蒸馏权重，缓解新条件适应与旧知识保持的冲突。
4. **消融与部署验证**：比较两个模块的单独及组合效果，检验天气顺序与旧域重访，测量推理和存储开销。

口头补充：若原约束下累计遗忘仍明显，可讨论固定预算特征回放；若更新成本或共享参数干扰成为主要限制，可讨论轻量适配器。
