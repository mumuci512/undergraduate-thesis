# P0 一页实验协议

日期：2026-11-16（Asia/Shanghai）；范围：落实[导师反馈计划P0](../../01_literature/comparisons/ADVISOR_FEEDBACK_RESEARCH_2026-11-16.md#7-建议的下一步执行计划)。这是本轮工程校准的工作协议；论文最终协议、主方法及ER容量未因此定案。

2026-11-17按用户要求及[D-012](../../00_management/DECISIONS.md)更新后续数据划分／正式评测规则；已完成P0的历史val结果不变。本轮只沉淀规范，不执行P1。

| 项目 | 本轮固定规则 |
|---|---|
| 任务 | RGB道路场景、固定Cityscapes 19类、完整像素监督的域增量；ignore=255，trainId=0–18，`reduce_zero_label=False`。labelIds只映射一次，已为trainIds的不再映射。 |
| 训练边界 | 阶段式、已知训练切换点；源域CS，后续Fog→Rain→Snow→Night保留为文献主序。P0只做Fog短训资源校准，不执行整条链。 |
| 数据版本 | 复用现有官方split：CS train/val=2975/500；ACDC Fog、Rain、Snow各400/100，Night400/106。具体样本及SHA固定在`remote/manifests/`，不以扩展版ACDC全部标注数量代替本轮数量。 |
| 历史权限 | 不把“禁止回放”设为统一限制。Source不更新；FT只用当前域；ER可保留过去已到达域的图像与真值，容量及抽样在P1按实测预算预先锁定；两者均不提前访问未来域。MILE参照保留论文所需原型/专家。Joint单列全训练集离线参考，披露其未来数据权限，不进入顺序方法的同权限排名。 |
| 训练／验证划分 | P0短训仅用Fog train固定前32张作资源校准，该历史记录不变。后续官方train完整用于训练，官方val用于调参／早停／模型选择；已有官方val/test，不再从train另扣验证集或自建测试集，也不把val/test并入训练。既有manifest记录train/val无同图SHA重叠，本轮确认当前路径存在；未重新哈希全量数据。ACDC共享录制目录，不能声称邻帧／地理完全独立。 |
| 正式测试与官网 | 官方test用于最终评价；ACDC隐藏test标签，必须按官方协议提交预测并以官网回执登记正式测试成绩，保存模型／提交包SHA、推理配置、提交ID及时间。val本地成绩单列，不冒充test，不用test反馈调参。ACDC账号已注册、待官方审核，当前记“待官方评测”；已完成906张Source评价是val结果。公开源权重上游已使用CS val监控，不称独立盲测。 |
| 源权重 | OpenMMLab官方B5 Cityscapes完整分割权重`87a052ec`，共同起点为已完成ImageNet-1K→Cityscapes训练的公开模型，不在本轮重新训练160k源阶段；严格加载全部980键。权重SHA及上游配置见`remote/prepare.json`与[配方审计](recipe/RECIPE_AUDIT.md)。 |
| 模型 | MiT-B5层数[3,6,40,3]、分割头256通道、19类；单GPU将SyncBN换为普通BN并严格保留参数/统计。未实现MILE专家、原型或路由。 |
| 预处理与输入 | 文件BGR→RGB；mean=[123.675,116.28,103.53]，std=[58.395,57.12,57.375]。短训随机缩放0.5–2、1024²裁剪、翻转和颜色扰动；pad图像0/标签255。 |
| 测试 | 固定源模型，`eval()`，FP32，无在线更新、缓存或时序状态；模型只接收图像及几何元数据，不提供真实天气域ID。域标签只在模型外分组统计。输入按(2048,1024)等比缩放，1024²滑窗、stride768；无多尺度或翻转增强，恢复原图尺寸计分。 |
| 指标 | 每域全split累计19×19混淆矩阵，排除255；IoU_c=TP_c/(TP_c+FP_c+FN_c)，mIoU为19类宏平均。报告每域、五域等权均值和最差域；缺类须显式处理。本轮五域均有19类有效union。P1起补阶段×域矩阵及旧域最大历史成绩−当前成绩的平均遗忘，不能用P0源模型单行计算遗忘。 |
| 资源校准 | RTX3080 20GB，1024²、microbatch1、FP16 AMP、200次真实优化更新；AdamW主干lr6e-5、头lr×10、weight_decay0.01，常数学习率只用于测速；剔除前20步报告吞吐。训练峰值在保存/重载前捕获，另记录重载校验；不把本次短训成绩当正式FT结果。 |
| MUSES | RGB-only；官方train/val/test与夜雨、夜雪交集见[muses/AUDIT.md](muses/AUDIT.md)。test真值不公开，不能生成本地test mIoU。P0清点文件及标签，不把未下载RGB整包写成已获得训练数据。 |
| 复现与比较范围 | 本轮是“公开SegFormer-B5源模型校准”，不称MILE复现；MILE确切源权重、头宽、完整训练配方及val/test口径仍有缺项。NVlabs原版768头与本次256头分列，对标本权重官方单尺度82.25，而不是原版多尺度84.0。 |

后续准入：源模型口径核对、200步有限loss/梯度与保存重载通过、20GB资源实测和MUSES标签清点完成后，可进入P1的有限调参及FT/ER准备；P0不启动P1正式长训。具体证据见本目录`README.md`。
